Word Racing v2.2.0 — 离线版

使用方法：
1. 将整个 ZIP 解压到固定文件夹，保留 word-racing 内部目录结构。
2. 双击 index.html，在 Chrome 或 Edge 中打开。
3. Windows 也可双击“启动游戏.bat”，使用默认浏览器打开。

不需要安装 Node.js、Python 或启动服务器。词库和 Three.js 已包含在发布包中。

每日默认目标45个不同词，每词双向完成奖励2燃油；完成45词另奖10燃油。
45词基础奖励共100燃油，可跑10圈。独立验证另有装备奖励，成就奖励另计。

学习存档保存在当前浏览器的本地存储中。
从旧版升级前，先在原页面设置中导出存档；在新版页面导入。
localhost 版和离线文件版不会自动共享存档。
更换浏览器、移动发布文件夹或清理浏览器数据可能影响存档访问，请定期导出备份。

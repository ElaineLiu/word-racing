# 单词音标与发音设计

## 目标

为本地使用的自适应学习流程补充英式音标和离线真人发音。默认声音为 `en-GB-RyanNeural`，语速为 `-10%`。音频在开发阶段批量生成并随离线包分发，运行时不联网。

## UC1：首次正面接触单词

1. 新词介绍页展示单词和音标。
2. 页面首次显示该词时自动播放一次发音。
3. 学习者可以点击扬声器重复播放。
4. 同一任务因界面刷新重复渲染时，不重复自动播放。

## UC2：学习卡与提示卡

1. 学习卡、巩固提示卡和语境讲解卡展示单词、音标、释义和合格例句。
2. 卡片首次显示时自动播放一次发音。
3. 手动点击扬声器可重复播放，不计为答题帮助，也不改变学习证据。
4. 切换任务或离开学习页时立即停止上一段音频。

## UC3：独立作答防泄露

1. 英文选中文题展示英文和音标，并在任务首次显示时自动播放。
2. 中文选英文题在提交答案前不展示音标，也不播放发音。
3. 语境填空题在提交答案前不展示目标词音标，也不播放目标词发音。
4. 发音失败不阻断答题，也不改变奖励和学习状态。

## UC4：用户设置与存档

1. 设置菜单提供“自动播放发音”开关，默认开启。
2. 设置按用户保存在 `GameState.preferences.autoPronunciation`。
3. 关闭自动播放后仍可使用手动扬声器。
4. 旧存档升级时补齐默认设置；导入、导出和重置沿用统一 `GameState` 数据。

## UC5：音频生成与离线构建

1. 生成脚本读取当前中考词库，为每个词生成固定编号的 MP3。
2. 清单记录词条编号、单词、声音、语速和源文本，重复运行时跳过未变化文件。
3. 校验脚本要求当前词库每个词都有非空音频且清单一致。
4. 构建脚本将音频目录复制到离线包，`file://` 打开时可直接播放。

## 公开接口

- `PronunciationPlayer.play(word, options)`：播放当前词发音；自动播放提供稳定去重键。
- `PronunciationPlayer.stop()`：停止并释放当前音频。
- `audioPathForWord(word)`：从稳定词条编号生成音频路径。

## 验收标准

- 新词介绍、学习卡和英文选中文题显示音标并自动播放一次。
- 重复渲染不重复自动播放，手动点击始终允许重播。
- 中文选英文和语境填空在作答前不泄露发音或音标。
- 自动播放设置按用户隔离，旧存档无损升级。
- 缺失或损坏的音频会使数据校验失败，播放错误不会阻断学习。
- 完整测试、数据校验、离线构建和真实浏览器流程通过。

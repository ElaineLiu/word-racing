# 45词每日目标与奖励验证

## 规则
- 默认45个不同词，每轮10词，最后一轮5词；引入上限15新词/30旧词，复习替代和主动加练保持现有行为。
- 完成一个词的双向练习或独立验证奖励2燃油；45词完成额外10燃油，每个本地日期一次。正常完成45词基础学习奖励100燃油；一次性成就另计。
- 只看卡、不会或单向通过不发奖励。任务不足不补足，额外不同词加练仍可获2燃油。
- 旧余额、较高旧逐词凭据保留，因此升级当天包含旧奖励时可能超过100。原学习验证文档中的15词/7及10燃油规则由本次调整替代。

## 自动验证
`npx vitest run`：63文件、854测试通过。真实对象覆盖45练习词、15练习+30独立、45独立均100燃油；44词88；第45词发2+10；刷新、重复提交、加练和跨日；旧7燃油记录不回扣、不重领；奖励凭据与余额同一次持久化。实际Game方法两场5圈，余额100→50→0。

`npm run build`通过，更新本地预览构建。

## 浏览器验证
使用隔离浏览器会话及真实词库，设30个旧接触词测试数据，通过页面学习卡和双向练习完成45词、5轮。页面显示今日学习获得100燃油，GameState余额100，独立通过0，装备0，新词15。刷新后45/45及100余额保留，页面错误列表为空。截图在本地tmp/45-word-learning-result.png。未改孩子的浏览器存档。

45词只提高任务量，不保证每个孩子恰好学习15–20分钟；赛车按10燃油/圈支持10圈，实际游戏时长取决于圈速。

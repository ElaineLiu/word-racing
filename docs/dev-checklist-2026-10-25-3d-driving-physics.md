# 3D 驾驶物理优化开发检查清单

## 开始开发前

- [x] 查阅 `ISSUE_LOG.md` 中已解决条目及预防措施
- [x] 查阅 `design/3d-track/speed-tuning.md`，确认当前 3D 加速设计
- [x] 确认测试策略：真实 `Car3D` / `AIController`，覆盖帧率、滑行、制动、倒车和转向

## 编写代码时

- [x] 3D 全油门采用随速度衰减的非线性加速，最高时速保持 300 km/h
- [x] 松开油门后按滚阻和空气阻力滑行，不立即归零
- [x] 制动与倒车分离：行驶中按倒车键只制动，停稳、松开并再次按下后倒车
- [x] 倒车最高速度与加速度低于前进
- [x] 高速转向角速度下降，过弯半径随速度增大
- [x] 油门、刹车和转向输入平滑过渡
- [x] AI 根据路径转向负荷提前收油或制动
- [x] 2D 物理和既有公开方法保持兼容
- [x] 数据仍由现有 `Car` / `RaceSession3D` 调用链流动，无新增事件总线

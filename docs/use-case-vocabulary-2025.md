# UC-VOCAB-2025：2025 上海中考词汇手册升级

## 目的

以本地《2025 上海中考考纲词汇用法手册》为主要内容来源，升级唯一运行时词库 `shanghai-zhongkao`。PDF 只作为本地输入，不进入 Git 或构建产物。

## 输入与输出

- 输入：本地 PDF（不提交到仓库）
- 中间结果：`data/sources/2025-shanghai-handbook-extracted.json`
- 运行时词库：`data/words-shanghai-zhongkao.json`
- 运行时仍只保留一个词库 ID

## 处理规则

1. 先提取英文词条，再清理页眉、页脚、页码和水印。
2. 保留词形变化、词性、中文释义、搭配、用法、例句和来源页码。
3. `adv.`、音标和标点等嵌入字体异常进入规范化阶段，不直接丢弃。
4. 例句可直接采用手册例句；仅修复明确的断行和识别错误。
5. 词组搭配可以生成独立选择、补全和用法判断题。
6. 旧词条优先按规范化英文词复用 ID；新增词从最大 ID 之后编号。
7. 低置信度词条保留 `needs_review`，不得进入默认题目集合。

## 验收

- 解析器输出稳定且可重复
- 词条和英文词唯一
- 题干只有一个合理答案
- 例句、翻译和目标词关系可验证
- 旧存档中的词汇进度可继续读取
- 全量测试、严格词库校验和正式构建通过

## OCR 与词条边界

- PDF 共 359 页；每页独立 OCR 并校验非空、无错误后再按页码合并。
- 第一章词汇正文为 PDF 第 7–284 页；第二至第四章作为搭配、词形和辨析题素材，不计入主词条总数。
- 主词、大小写不同的同形词和“变形”必须分开处理：`May/may`、`Miss/miss` 分别保留；派生词归入 `word_forms`。
- 当前正文解析结果为 1,639 个大小写精确唯一的主词条，另含 644 个归属到主词的词形。
- OCR 或版式低置信记录通过 `source2025.needs_review` 标记；题目生成由 `question_eligibility` 控制可用素材。

# 独立验证与旧进度迁移

填空题只显示挖空后的句子。没有可靠例句的词可以练习词义，不能通过简单题回退获得复杂能力认证。已标记需复核的例句停止展示，原文保留供审校。

查看帮助或答错后显示答案，同词当天继续作答属于辅助练习。辅助完成不记为错词，不推进独立通过，也不发测试答对和正确率奖励。刷新页面会保留辅助状态。

Basic、Advanced各在两个不同本地日历日期独立通过，才计入Stable Mastery。同一天重复通过只计一次；独立答错会清除对应能力的验证日期。Historical Passes Awaiting Verification表示旧记录缺少新版独立证据，旧通过仍保留在legacyEvidence中。

Auto根据学习进度出题。Verify Learned Words只安排待复核和跨日检查，不混入新词；当天没有到期题目时保留未完成套题。

## 旧备份

应用初始化时按精确单词重新绑定当前词库ID。已从词库移除的词保留为Archived，不会拿其旧ID指向的另一个词出题。经济余额、历史成绩与已获成就不追溯撤销。

需要在其他机器使用迁移备份时，可生成独立输出文件：

```powershell
node scripts/migrate-assessment-data.mjs old-backup.json migrated-backup.json
```

脚本拒绝覆写原文件或已有输出。备份是私人学习数据，应保留在本机，不提交到仓库。

## 验证

真实对象回归覆盖辅助后刷新、同日重做、跨日掌握、旧ID错配、缺失词、幂等迁移、空复核保留会话及完整辅助套题。提交前完整测试为62个文件、834个测试通过；严格词库校验和构建通过。桌面浏览器完成10道辅助练习后，独立通过及测试奖励均为0。

OCR内容尚需全量人工审校；结构校验通过不等于原文审校完成。
